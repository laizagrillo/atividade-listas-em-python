# 🚀 Lógica de Programação com Python: Do Básico ao Prático

Este repositório contém um caderno interativo do Google Colab projetado para o aprendizado e prática dos fundamentos da linguagem Python. O material aborda desde a manipulação básica de variáveis até o desenvolvimento de pequenos sistemas interativos e jogos lógicos.

## 📋 Conteúdo do Notebook

O caderno está estruturado em tópicos evolutivos de aprendizado:

1. **Entrada de Dados e Formatação de Strings (`f-strings`)**
   - Captura de dados com `input()` e conversão de tipos (`str`, `int`).
   - Formatação e concatenação elegante de mensagens de texto.

2. **Estrutura de Dados: Listas**
   - Criação de coleções de dados (Listas de funcionários, idades, frutas, produtos e preços).
   - Acesso a elementos por índice.

3. **Operadores Matemáticos e Aritmética**
   - Prática com operadores: soma (`+`), módulo/resto (`%`), potência (`**`) e cálculo de raízes.

4. **Estruturas Condicionais (`if`, `elif`, `else`)**
   - Controle de fluxo e tomada de decisão com base em condições lógicas.

5. **Jogos Desenvolvidos**
   - **Par ou Ímpar:** Jogo interativo contra outro jogador humano.
   - **Pedra, Papel ou Tesoura:** Clássico jogo de tomada de decisão com lógica de múltiplos cenários de empate e vitória.
   - **FizzBuzz:** Algoritmo clássico de lógica e divisibilidade matemática.

6. **Sacolão & Controle de Estoque (Mini-Sistema de Vendas)**
   - Uso do laço `for` integrado com a função `zip()` para percorrer múltiplas listas simultaneamente.
   - Cadastro dinâmico de novos produtos e preços usando `.append()`.
   - Remoção inteligente de produtos específicos do estoque utilizando `.pop()` e busca de índices com `.index()`.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebook
